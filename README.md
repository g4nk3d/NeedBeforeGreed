# Need Before Greed

A loot-table game of bluff and nerve for World of Warcraft, part of the Nether addon family.

You've joined a pickup group. Eight items drop. Everyone picks **Need**, **Greed** or **Pass** in secret, and
everyone's class is secret too. Needers roll before Greeders, so Needing an item your class can't use is
tempting... but any player may **call ninja** on a Needer. The accused shows their class card: caught, they
lose reputation and their Need is cancelled; honest, the caller loses it instead. Lose all three reputation
and you're kicked from the group.

## Features

- Five dungeons, each with its own loot table (Classic proficiencies decide who can use what).
- Five other players with their own habits and party-chat tells: Snaggle, Sister Maelle, Brokk Ironpaw,
  Pellwick, Old Tamsin and Vexa (four sit at each table).
- The Ledger at the end of every run reveals what each item was worth. Bronze, silver and gold medals.
- A daily run: the same dungeon, classes, drops and dice for everyone, with a shared daily scoreboard
  (every score is checked by replaying the run).
- Twelve achievements.
- Your run is kept after a /reload or a disconnect. Combat pauses the game at once.
- Light: nothing runs while the window is closed.

## Commands

- `/nbg` or `/needbeforegreed`: open or close the game
- `/nbg daily`: today's daily run
- `/nbg perf`: frame time and memory
- `/nbg debug`: errors and missing art
- `/nbg reset`: forget this character's records (asks first)

Keys at the table: `1` `2` `3` (or `N` `G` `P`) to pick, `Space` for no call or to skip ahead, `C` for
who can use what, `Esc` for the menu.
